# AWS Cloud Security Engineering Portfolio

## About

This repository documents my hands-on journey into AWS Cloud Security Engineering, Infrastructure as Code (IaC), Cloud Governance and DevSecOps.

The project focuses on implementing practical cloud security controls using Terraform and AWS services.

## Objectives

- Implement secure AWS infrastructure using Terraform.
- Explore multi-account AWS governance and security.
- Configure identity and access management.
- Implement threat detection and security monitoring.
- Automate security remediation.
- Apply cloud encryption and data protection practices.
- Integrate security scanning into CI/CD pipelines.
